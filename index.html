Политика конфиденциальности

Дата вступления в силу: 14 сентября 2026 г.

Эта Политика конфиденциальности описывает, как приложение Shiftly обрабатывает данные при использовании календаря смен, расчёта заработка, шаблонов смен, заметок, статистики и связанных функций.

Русский English

1. Какие данные обрабатывает Shiftly

Shiftly позволяет пользователю самостоятельно вводить данные, необходимые для работы приложения. К таким данным могут относиться:

  • рабочие смены, даты, время начала и окончания работы;
  • ставки оплаты, правила доплат, бонусы, KPI и удержания;
  • названия и шаблоны смен и рабочих графиков;
  • заметки, добавленные пользователем к датам или сменам;
  • настройки отображения, статистики и календаря.

Эти данные используются для отображения календаря, расчётов заработка, статистики и других функций приложения.

2. Где хранятся данные

Данные, которые пользователь вводит в Shiftly, хранятся локально на устройстве пользователя в хранилище приложения.

Shiftly не требует создания пользовательского аккаунта для работы основных функций приложения.

3. Передача данных третьим лицам

Shiftly не продаёт введённые пользователем данные и не передаёт содержимое календаря, сведения о зарплате, заметки или шаблоны смен третьим лицам для рекламных целей.

Если пользователь самостоятельно использует функцию экспорта или отправки графика, данные передаются только в выбранное пользователем приложение или сервис через стандартные функции Android.

4. Экспорт и отправка графика

Shiftly может создавать файл с графиком работы, например PDF, по запросу пользователя. Такой файл создаётся только после действия пользователя.

После создания пользователь самостоятельно выбирает, сохранить файл на устройстве или отправить его через установленное стороннее приложение. Политика конфиденциальности выбранного стороннего приложения применяется отдельно.

5. Разрешения устройства

Приложение может использовать только те разрешения Android, которые необходимы для его функций. Например, вибрация может использоваться для интерфейсной обратной связи.

Shiftly не использует разрешения для доступа к контактам, SMS, звонкам, точному местоположению, камере или микрофону для основных функций приложения.

6. Хранение и удаление данных

Данные хранятся на устройстве до тех пор, пока пользователь не удалит их через функции приложения, не сбросит данные приложения в настройках Android или не удалит приложение.

В Shiftly доступны функции изменения и сброса пользовательских данных, включая график и связанные настройки.

7. Безопасность

Мы стремимся минимизировать объём обрабатываемых данных и использовать стандартные механизмы безопасности Android для локального хранения данных.

Ни один способ хранения данных не может гарантировать абсолютную безопасность, поэтому пользователю рекомендуется защищать своё устройство паролем, PIN-кодом или биометрической блокировкой.

8. Дети

Shiftly не предназначен для сбора персональных данных детей. Приложение не запрашивает дату рождения и не создаёт пользовательские профили с персональными идентификаторами.

9. Изменения политики

Политика может обновляться при добавлении новых функций или изменении способов обработки данных. Актуальная версия будет размещаться по этой же ссылке.

10. Контакты

По вопросам конфиденциальности можно связаться с разработчиком Shiftly через контактный адрес электронной почты, указанный на странице приложения Shiftly в Google Play.

Privacy Policy

Effective date: September 14, 2026

This Privacy Policy explains how Shiftly handles data when users use the shift calendar, earnings calculator, shift templates, notes, statistics, and related features.

1. Data processed by Shiftly

Users may enter information such as:

  • work shifts, dates, start times and end times;
  • pay rates, premium rules, bonuses, KPI values and deductions;
  • shift templates and work schedule templates;
  • notes added to dates or shifts;
  • calendar, display and statistics settings.

This information is used to provide calendar, earnings calculation, statistics and related app functionality.

2. Data storage

Data entered into Shiftly is stored locally on the user's device in the application's local storage.

Shiftly does not require a user account for its core functionality.

3. Sharing with third parties

Shiftly does not sell user-entered data and does not share calendar content, salary information, notes or shift templates with third parties for advertising purposes.

If a user chooses to export or share a schedule, the information is sent only to the application or service selected by the user through standard Android sharing features.

4. Schedule export and sharing

Shiftly may create a work schedule file, such as a PDF, when requested by the user. The file is created only after an explicit user action.

The user then chooses whether to save the file locally or share it through another installed application. The third-party application's privacy policy applies separately.

5. Device permissions

Shiftly may use only Android permissions required for app functionality, for example vibration for interface feedback.

Core Shiftly functionality does not require access to contacts, SMS, calls, precise location, camera, or microphone.

6. Data retention and deletion

Data remains on the user's device until the user removes it using in-app controls, clears the application's storage through Android settings, or uninstalls Shiftly.

7. Security

Shiftly aims to minimize data processing and relies on standard Android security mechanisms for local app storage.

No storage method can guarantee absolute security. Users are encouraged to protect their device with a password, PIN, or biometric lock.

8. Children

Shiftly is not designed to collect personal information from children. The app does not request a date of birth and does not create accounts containing personal identifiers.

9. Changes to this policy

This policy may be updated when new functionality is added or data handling changes. The current version will remain available at this URL.

10. Contact

For privacy questions, users may contact the Shiftly developer using the developer contact email shown on the Shiftly Google Play listing.
